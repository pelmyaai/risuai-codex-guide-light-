RisuAI + ChatGPT Codex 연결 가이드

Windows 데스크탑에서 RisuAI를 개인 ChatGPT/Codex 계정에 연결해 테스트하는 라이트 가이드입니다. 각자 자기 계정으로 로그인하고, 로컬 프록시는 RisuAI를 쓰는 동안만 켜둡니다.

Windows RisuAI Desktop clawgate 개인용 테스트

먼저 읽기

이 방식은 OpenAI 공식 API 키 연동이 아니라, 독립 오픈소스 로컬 프록시를 사용하는 개인 테스트용 설정입니다. 계정 공유, 재판매, 대량 자동 요청, 상업 서비스 운영 용도로 사용하지 마세요.
  • ChatGPT 계정, 로그인 코드, 토큰 파일, API 키는 절대 공유하지 않습니다.
  • RisuAI와 clawgate는 같은 PC에서 실행하는 데스크탑용 설정입니다.
  • 문제가 생기면 프록시를 끄거나 안정 모델 설정으로 되돌립니다.

전체 흐름

1

clawgate 설치

2

Codex 로그인

ChatGPT 계정으로 장치 코드 인증을 완료합니다.

3

프록시 실행

RisuAI를 쓰는 동안 clawgate 창을 켜둡니다.

RisuAI 설정

Custom API를 Anthropic Claude 형식으로 연결합니다.

1. 설치

clawgate는 RisuAI와 ChatGPT/Codex 사이를 이어주는 작은 로컬 연결 프로그램입니다. 처음 한 번만 설치하면 됩니다.

  1. Windows 시작 메뉴에서 PowerShell을 검색해서 엽니다.
  2. 아래 명령어를 그대로 복사해 PowerShell에 붙여넣고 Enter를 누릅니다.
irm clawgate.org/install.ps1 | iex

화면에 Installation complete!가 보이면 설치가 끝난 것입니다.

  1. PowerShell 창을 닫았다가 다시 엽니다.
  2. 아래 명령어로 설치가 잘 되었는지 확인합니다.
clawgate --help
도움말이 여러 줄로 나오면 성공입니다. clawgate를 찾을 수 없다고 나오면 PowerShell을 새로 열었는지 확인하세요.

2. 로그인

PowerShell에서 로그인 명령을 실행합니다.

clawgate login

화면에 표시되는 주소로 들어가 코드를 입력하고 ChatGPT 계정으로 승인합니다. 계속 버튼이 비활성화되어 있으면 ChatGPT 보안 설정에서 Codex용 장치 코드 인증을 켭니다.

로그인은 매번 할 필요가 없습니다. 토큰이 풀렸거나 Not logged in 오류가 날 때만 다시 로그인하면 됩니다.

3. 프록시 실행

안정 모드는 아래 명령어를 사용합니다.

clawgate

GPT-5.5 실험 모드는 아래처럼 실행합니다.

clawgate --bigModel=gpt-5.5
GPT-5.5는 환경에 따라 경고가 뜨거나 실패할 수 있습니다. 안정적으로 쓰려면 기본 실행 또는 gpt-5.4를 사용하세요.

정상 실행되면 이런 주소로 대기합니다.

http://127.0.0.1:8082

4. RisuAI 설정

RisuAI에서 모델을 Custom API로 선택하고 아래 값으로 설정합니다.

URL http://127.0.0.1:8082
키/패스워드 dummy
요청 모델 claude-3-opus
포맷 Anthropic Claude
토크나이저 Claude
Response 스트리밍 켜기
고급설정 직접보내기 요청 끄기
Ooba 모드 끄기
clawgate 창에 claude-3-opus -> gpt-5.4 또는 claude-3-opus -> gpt-5.5가 보이면 연결 성공입니다.

5. 바로가기 만들기

매번 PowerShell에 명령어를 치기 번거롭다면 바탕화면 바로가기를 만들 수 있습니다.

  1. 바탕화면 빈 곳을 우클릭합니다.
  2. 새로 만들기 → 바로 가기를 선택합니다.
  3. 항목 위치에 아래 경로를 입력합니다.
C:\Users\HR\.clawgate\bin\clawgate.exe

GPT-5.5 실험 모드로 바로 실행하려면 항목 위치를 아래처럼 입력합니다.

C:\Users\HR\.clawgate\bin\clawgate.exe --bigModel=gpt-5.5
  1. 이름은 RisuAI GPT 연결처럼 알아보기 쉽게 적습니다.
  2. 마침을 누릅니다.
RisuAI를 쓰기 전에 이 바로가기를 더블클릭하세요. 열린 검은 창을 닫으면 RisuAI 연결도 끊깁니다.

스크린샷 자리

공개용 이미지는 이메일, 인증 코드, 계정 ID, 개인 프롬프트를 가린 뒤 넣으세요. clawgate 실행 화면은 토큰이나 이메일이 보이지 않으면 예시로 쓰기 좋습니다.

자주 나는 오류

Stream must be set to true

RisuAI의 Response 스트리밍을 켭니다.

Not logged in

PowerShell에서 clawgate login을 다시 실행합니다.

RisuAI가 연결되지 않음

clawgate 창이 켜져 있는지, URL이 http://127.0.0.1:8082인지 확인합니다.

GPT-5.5 경고 또는 실패

바로가기 대상에서 --bigModel=gpt-5.5를 지우거나 --bigModel=gpt-5.4로 바꿉니다.

공개 공유 체크리스트

  • 토큰 파일과 계정 정보는 포함하지 않습니다.
  • 스크린샷의 이메일, 코드, callback URL, 계정 ID를 가립니다.
  • 제목에 공짜 API, 무제한, 우회 같은 표현을 쓰지 않습니다.
  • 개인 데스크탑 테스트용이라는 문구를 남깁니다.
이 문서는 개인 테스트용 설정 메모입니다. OpenAI, Anthropic, RisuAI, clawgate의 공식 문서와 약관을 각자 확인하세요.
